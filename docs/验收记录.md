用户指定接口：`https://api.routin.ai/v1`。

用户指定模型：`deepseek-v4.1-flash-expires-on-0910`。

凭证变量 `routin_ai_apikey` 位于 Windows 系统环境变量，已成功读取，未输出或保存其值。

`GET /v1/models` 成功，共返回 94 个模型；未找到指定模型。绕过 MAF，直接请求同一模型的基础文本 Chat Completions，也返回 HTTP 500。服务的错误含义为：所有分组中均没有该模型可用的 AI 提供商。

结论：当前阻塞在指定模型的服务可用性，不能用离线结果宣称真实验收完成，也不擅自替换用户指定模型。待用户提供该接口下可用模型名或恢复原模型后，运行真实探针，再进入阶段 2。
