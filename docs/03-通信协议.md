# 本地通信协议 v1 草案

编码为 UTF-8，每行一个 JSON 对象，最大消息长度 1 MiB。标准错误用于诊断。任何协议内容禁止包含 API 密钥。桌面主进程与 Worker 首先握手确认版本，不兼容时阻止执行。

## 命令

统一信封字段：`version`、`requestId`、`method`、`payload`。每个命令恰好返回一个响应；执行过程通过独立事件发出。错误包含稳定英文错误码和中文 message。

| method | 含义 |
| --- | --- |
| hello | 协议版本、Worker 版本和能力 |
| project.open | 校验工作区并打开项目 |
| run.start | 创建执行，指定项目、用户输入和提供商配置编号 |
| run.cancel | 取消指定执行，包括等待中的审批 |
| approval.respond | 响应某个执行的具体工具调用及参数摘要 |
| run.continue | 核对中断状态后创建新执行，不自动重放工具 |
| history.list | 分页列出任务与执行 |
| events.list | 按 runId、afterSequence 分页恢复事件 |
| workspace.diff | 获取当前差异及对应文件快照 |
| worker.shutdown | 取消运行、持久化并退出 |

## 事件

字段：`version`、`type`、`taskId`、`runId`、`sequence`、`timestamp`、`payload`。sequence 在每个 Run 内严格递增。先持久化后发送；UI 按 `(runId, sequence)` 去重。文本增量批量写入；重连优先读取持久化快照及后续事件。

事件类型：`run.started`、`message.delta`、`tool.started`、`tool.completed`、`approval.requested`、`approval.resolved`、`artifact.created`、`usage.updated`、`run.completed`、`run.failed`、`run.cancelled`、`run.interrupted`。

工具事件关联 toolCallId。审批与 runId、toolCallId、规范化参数哈希、工作区及有效期绑定，禁止跨执行复用。终态之后不发送新的业务事件。取消请求幂等；响应表示已接收请求，终态事件表示清理完成。

## 类型生成

第 2 阶段以 JSON Schema 维护唯一协议定义，生成 C# DTO 和 TypeScript 类型；CI 验证生成文件无漂移。当前是阶段 1 的协议审阅文档，不宣称已有生成器或实现。
